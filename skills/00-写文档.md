# 写文档
STATE ✓ 2026-11-26 docx/pptx/xlsx 已实测；pdf 未实测（本机无 fpdf2 与 Android 字体）｜SCOPE md → docx/xlsx/pptx/pdf，纯 JS + 纯 py，Termux/Linux 同源｜SCRIPT 见命令

## 何时用
要把 md / 笔记 / 分析结果变成能发给人的交付物（报告、表格、幻灯片、PDF），或把内部 md 转成对外格式。

## 命令
```bash
S=~/.config/cli-agent/skill
node $S/md2docx.mjs in.md out.docx --title "标题"   # Word，A4+页码
python3 $S/md2xlsx.py in.md out.xlsx                # Excel，每个 md 表格一个 sheet
node $S/md2pptx.mjs in.md out.pptx --theme 1F3864    # PPT，`#`/`##` 各起一页
python3 $S/md2pdf.py in.md out.pdf                   # PDF，中文 A4，默认横排；加 --portrait 竖排
```

## 参数 / 退出码
| 脚本 | 参数 | 退出码 |
|---|---|---|
| `md2docx.mjs` | 输出缺省同名 `.docx`；`--title` 加封面标题 | `0` ｜ `1` 生成失败 ｜ `2` 用法/选项错或文件不存在 |
| `md2xlsx.py` | 输出缺省同名 `.xlsx` | `0` ｜ `2` ｜ `6` md 内无表格 |
| `md2pptx.mjs` | 输出缺省同名 `.pptx`；`--theme` 6 位十六进制，`#` 可省 | `0` ｜ `2` 用法/选项错或文件不存在 |
| `md2pdf.py` | `--size` 字号（默认 8）、`--portrait` 竖排（默认横排） | `0` ｜ `1` 无参数或生成失败 ｜ `2` 选项错 |

## 失败处置
| 现象 | 处置 |
|---|---|
| `Cannot find module 'docx'` / `pptxgenjs` | `cd ~/.config/cli-agent/skill && npm i docx pptxgenjs` |
| xlsx `exit 6` | md 里没有 `\|` 表格，先补表格 |
| pdf 报缺字形（如 `✓`） | 系统字体不含该符号，换文字表述 |
| pdf 中文为方块 | `MD2PDF_CN_FONT=/path/xxx.ttf` 指定 TrueType（CFF/OTF 不支持） |

## 陷阱
- 交付前必须回读自检，不要只看文件大小：`md2md out.docx`、`md2md out.pptx`、`openpyxl.load_workbook(out.xlsx)`。
- docx 表格要同时给 `columnWidths` 和每格 `width`，只给一个在 Google Docs 会塌成单列。
- pptx 色须 6 位十六进制：`--theme` 自动去 `#`，非法值 exit 2；脚本内改色同样不带 `#`、不用 8 位，否则文件损坏。
- pptx 每页 bullet ≤7、表格 ≤9 行（含表头），超出自动续页：标题加「（续）」、表格重复表头，不丢内容；成功行 JSON 的 `pages`/`continued` 给出实际页数与续页数。
- pptx 的 `letterSpacing` 无效，真正选项是 `charSpacing`；`shadow.offset` 必须 ≥ 0。
- 改现有 docx/pptx 不要重生成：解包 XML 改再 `zip -XrDy` 打包，避免丢样式。
- 需要精细模板（公司模板、目录页码刷新）时用 soffice 转 pdf 复核：`soffice --headless --convert-to pdf`。
